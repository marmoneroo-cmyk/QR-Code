# מערכת ניהול התפריט (Admin / CMS) — סקירה מלאה

מסמך זה מתאר **כל מסך** במערכת הניהול של הפלטפורמה (תפריט קוקטיילים אינטראקטיבי
יוקרתי, Next.js 16 / React 19), **מה הוא עושה**, ו**מה שיפרנו בו**. נכתב כדי
להעביר ל-GPT לשיפור נוסף.

> סטאק: Next.js 16 (Turbopack) · React 19 · TypeScript strict · Tailwind v4 ·
> Framer Motion · React-Three-Fiber. נתונים: Supabase + טיוטות ב-localStorage.
> אחסון תמונות/הפקה: Pollinations (חינם) + הסרת רקע.

---

## שיפורים גלובליים (חלים על כל מסכי ה-Admin)

1. **דו-לשוניות מלאה EN/עברית + RTL** — נוסף hook גלובלי `useLang` (נשמר
   ב-localStorage, מסונכרן בין טאבים). כל מסך משתמש בתבנית `t(en, he)`, וכל
   הטקסטים, התוויות, ה-placeholders וכפתורי הפעולה תורגמו. כשעברית פעילה הפריסה
   עוברת ל-`dir="rtl"`, והשדות מקבלים `dir` לוגי נכון (אנגלית `ltr`, עברית `rtl`).
2. **AdminShell אחיד** — מעטפת אחת לכל המסכים: סרגל ניווט עליון דביק, קישור חזרה
   לתפריט, מתג שפה **EN / עב**, כותרת + תת-כותרת + מפריד דקורטיבי, ו-slot לפעולות.
   תומך ב-props ייעודיים לעברית: `titleHe`, `eyebrowHe`, `subtitleHe`.
3. **טיפוגרפיה ממותגת** — כותרות: Playfair (אנגלית, נטוי) / Frank Ruhl (עברית).
   גוף: Garamond / Heebo. UI: Inter. צבע אקסנט: ענבר (amber) על שחור.
4. **תפריט הניווט (Toolbar)**:

   | נתיב | EN | עברית |
   |------|----|-------|
   | `/admin` | Composer | עורך |
   | `/admin/import` | Import | ייבוא |
   | `/admin/qr` | QR Codes | קודי QR |
   | `/admin/print` | Print Kit | הדפסה |
   | `/kiosk` | Kiosk | קיוסק |
   | `/admin/analytics` | Analytics | אנליטיקס |
   | `/changelog` | Build Log | יומן |

## המסכים

### 1. מרכז הניהול (Hub) — `/admin`
**מטרה:** עורך מרכזי לטיוטות ולתפריט.
**מה אפשר לעשות:**
- לראות **טיוטות** (localStorage, עם מונה): תצוגה מקדימה / עריכה / העתקת JSON / מחיקה.
- לראות את התפריט **המפורסם** (לקריאה בלבד).
- **+ קוקטייל חדש** → `/admin/new`.
- **ייצוא JSON** (העתקת כל הטיוטות ללוח).
- **Bulk Breakdown** — הפקת פירוק 3D לכל הטיוטות שאין להן שכבות מותאמות, ברצף.

**מה שיפרנו:** תרגום מלא לעברית (כרטיסי טיוטה, תוויות קטגוריה, מצב ריק); משוב
"הועתק!" עם היעלמות אוטומטית; אישור לפני מחיקה; אנימציית כניסה לכרטיסים.
**פערים לשיפור (ל-GPT):** אין חיפוש/סינון טיוטות לפי שם/קטגוריה; אין מחיקה
מרובה; קטע "מפורסם" הוא תצוגה בלבד ולא מקושר לעריכה.

---

### 2. קוקטייל חדש — `/admin/new`
**מטרה:** יצירת טיוטת קוקטייל מאפס (משתמש ב-`CocktailForm` במצב "new").
**מה שיפרנו:** דו-לשוני מלא (כותרת "הרכבת קוקטייל חדש"); תת-כותרת מסבירה את הזרימה
(פרטים → תמונת hero ב-AI → פירוק 3D אופציונלי → הופעה מיידית בתפריט).

---

### 3. עריכת טיוטה — `/admin/[slug]/edit`
**מטרה:** עדכון טיוטה שמורה (טעינה מ-localStorage לפי slug; ה-slug קבוע).
**מה שיפרנו:** מצב טעינה; דף 404 ידידותי אם הטיוטה לא נמצאה; תת-כותרת מזכירה
לאמת דרך קישור התצוגה המקדימה.
**פערים לשיפור (ל-GPT):** "Draft not found" ו-"Loading draft…" עדיין **באנגלית
בלבד**; ל-eyebrow "Editing Draft" חסר תרגום עברי. אין undo/ביטול שינויים.

---

### 4. טופס הקוקטייל — `CocktailForm` (משותף ל-new/edit)
**מטרה:** הזנת כל נתוני הקוקטייל. **סקשנים:**
1. **שם ותיאור** — שם EN (חובה) / שם HE / tagline EN / tagline HE; הצגת slug
   (אוטומטי, קבוע בעריכה, מתריע אם תפוס ביצירה).
2. **קטגוריה ותזונה** — dropdown (citrus/smoky/bitter/sweet/mocktail) + צ'קבוקסים
   (vegan / gluten-free / alcohol-free), תוויות דו-לשוניות.
3. **פרופיל טעמים (0–5)** — sweet / bitter / citrus / smoky / herbal.
4. **הערת בארמן** — טקסט EN + HE + שם הבארמן.
5. **תמונת Hero** — prompt + כפתור **Generate with AI** (Pollinations, חינם, ~10ש'),
   או **העלאת תמונה** (עד 4MB), עם תצוגה מקדימה.
6. **פירוק 3D (אופציונלי)** — כפתור הפקה מלאה (streaming ל-`/api/generate-breakdown`),
   התקדמות פר-שכבה (6 שכבות, אייקוני סטטוס), ובסיום רשת תצוגות.

**מה שיפרנו:** דו-לשוניות מלאה כולל RTL בטופס; מפות תוויות `DIETARY_LABEL`,
`FLAVOR_LABEL[axis][lang]`, `CATEGORY_LABEL`; ולידציה (שם EN + תמונה חובה) עם
הודעות שגיאה דו-לשוניות.
**פערים לשיפור (ל-GPT):** טעמים כ-text inputs (עדיף sliders); אין ולידציית
מימדי תמונה; אין undo; תת-הכותרת "Components Breakdown" קשיחה ולא ניתנת לעריכה.

---

### 5. קודי QR — `/admin/qr`
**מטרה:** הפקת QR לכל קוקטייל להורדה/הדפסה.
**מה אפשר לעשות:** מתג יעד **Breakdown** (פירוק 3D) מול **AR view** (מצלמה);
**הורדת הכול** (batch PNG); **הדפסת גיליון**; הורדת PNG בודד.
**מה שיפרנו:** דו-לשוני מלא; מיזוג התפריט המפורסם + טיוטות (מסומנות "Draft only");
QR ברמת תיקון שגיאות H, 600×600, ענבר על שחור (ממותג); CSS להסתרת פקדים בהדפסה.
**פערים לשיפור (ל-GPT):** אין הגדרות גיליון הדפסה (גודל/מרווח).

---

### 6. ערכת הדפסה — `/admin/print`
**מטרה:** כרטיסי שולחן (table-tent) עריכתיים להדפסה דו-צדדית.
**מה אפשר לעשות:** **כמות לעמוד** 1/2/4; **יעד QR** Breakdown/AR; **מטבע**
ILS/USD/EUR; צ'קבוקס **הערת בארמן**; **הדפסת גיליון** (A4, שוליים 12מ"מ).
**מה שיפרנו:** דו-לשוניות מלאה כולל RTL בתצוגת ההדפסה; פריסת כרטיס עריכתית
(קו דקורטיבי, קטגוריה, כותרת Playfair, tagline, hero, הערה, QR + מחיר); כללי
`@media print` ל-A4 לבן ללא פקדים.
**פערים לשיפור (ל-GPT):** אין תצוגה מקדימה של 4-up; המרת מטבע מוצגת כסמל בלבד
ללא שערים אמיתיים.

---

### 7. אנליטיקס — `/admin/analytics`
**מטרה:** לוח KPI (נתוני דמו; placeholder ל-POS/בקאנד עתידי).
**מה מוצג:** 4 כרטיסי KPI (צפיות / הזמנות / המרה% / פריט מוביל, עם מגמות);
2 sparklines (צפיות/הזמנות, 30 יום); טבלת פריטים מובילים; heatmap מעורבות לפי שעה.
**מה שיפרנו:** דו-לשוניות מלאה (תוויות KPI + מגמות); אנימציית כניסה; חצי מגמה
צבעוניים; הערה "Demo dataset · live data…".
**פערים לשיפור (ל-GPT):** כל הנתונים פסאודו-אקראיים — חסר חיבור לנתונים אמיתיים;
"30 יום" קשיח ללא בורר תאריכים.

---

### 8. ייבוא מסעדה — `/admin/import`
**מטרה:** סריקת תפריט מאתר מסעדה, הפקת תמונות hero ב-AI, וייבוא כטיוטות.
**זרימה:** URL → שם מסעדה (+slug אוטומטי) → לוגו (עד 1.5MB) → **Scan Menu**
(POST `/api/scrape-restaurant`, מזהה פלטפורמה: getmood.io / Wix / Tabit / HTML
גנרי) → טאבי קטגוריות → טבלת בחירת פריטים (צ'קבוקס, שם RTL, תיאור, קטגוריה
מנוחשת, סטטוס) → **Import** (streaming `/api/import-restaurant`, שמירת טיוטות
תוך כדי) → הפניה ל-`/admin`.
**מה שיפרנו:** דו-לשוניות מלאה (כולל הודעות שגיאה וזיהוי פלטפורמה); כיוון RTL
לשמות/תיאורים; ולידציית גודל לוגו; מעקב התקדמות פר-פריט; הגבלת `maxDuration=300`
(תקרת Vercel Hobby).
**פערים לשיפור (ל-GPT):** ולידציית URL מינימלית; regex לניחוש קטגוריה מוטה
לאנגלית; אין retry לפריטים שנכשלו.

### רכיב: BulkBreakdownButton
הפקת פירוק 3D ל-batch של טיוטות חסרות שכבות מותאמות: כפתור עם מונה, אישור עם
הערכת זמן, הרצה רצופה עם streaming, ורשימת התקדמות עם אייקוני סטטוס. דו-לשוני מלא.

## הזדמנויות שיפור מרוכזות (להציג ל-GPT)

**UX / מוצר**
- חיפוש + סינון טיוטות (שם/קטגוריה) ומחיקה מרובה ב-Hub.
- פרופיל טעמים כ-sliders ויזואליים במקום שדות מספר.
- תצוגה מקדימה חיה של פריסת 1/2/4-up ב-Print Kit.
- בורר תאריכים + חיבור נתונים אמיתי ל-Analytics.

**i18n (פערים שנותרו)**
- עמוד עריכת הטיוטה: "Draft not found", "Loading draft…", ו-eyebrow "Editing
  Draft" עדיין באנגלית — להוסיף תרגום + `eyebrowHe`.

**אמינות / נתונים**
- ולידציית URL וקובץ חזקה יותר בייבוא; מנגנון retry לפריטים שנכשלו.
- ניחוש קטגוריה דו-לשוני (כרגע ה-regex האנגלי קודם לעברי).
- המרת מטבע אמיתית (שערים) ב-Print Kit.

**ארכיטקטורה**
- ריכוז סגנונות inline (`fontFamily: var(...)`) ל-theme אחד.
- מערכת אקסנט גמישה (כיום ענבר קשיח) לתמיכה במותגי מסעדה שונים.

## English TL;DR (for GPT)
A bilingual (EN/HE + full RTL) admin/CMS for a luxury cocktail-menu app. Screens:
**Hub** (drafts CRUD + bulk 3D breakdown), **New/Edit** (CocktailForm: bilingual
fields, AI hero gen via Pollinations, streamed 3D layer breakdown), **QR** (QR
table tents, Breakdown/AR target, batch download/print), **Print Kit** (editorial
table tents, 1/2/4-up, currency, print CSS), **Analytics** (demo KPIs/sparklines/
heatmap — needs live data), **Import** (scrape restaurant site → AI heroes →
drafts). All wrapped in `AdminShell` (sticky nav + EN/עב toggle). Key gaps:
draft search/filter, slider flavor inputs, a few untranslated edit-page strings,
live analytics data, import retry + bilingual category guessing, real currency
conversion.
