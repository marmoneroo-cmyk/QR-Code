The project is an **interactive luxury experience platform for restaurants** — diners scan QR or visit menu URL, see beautifully presented items in 3D breakdown style, can share to socials. Restaurants manage their menu via CMS with the core differentiator being **AI-driven photo-to-3D-breakdown generation** (upload one product photo → automatic layer extraction + generation of missing components like splashes).

**Why:** Restaurants are stuck with boring PDF/static QR menus. This makes the menu itself a marketing/social-media asset that diners want to photograph and share. The shareability is the moat.

**How to apply:** Every feature decision should ask "does this make the menu more shareable / more premium / more useful for the restaurant owner without code?" If a feature only benefits us as developers, deprioritize. The user explicitly values **cinematic restraint** over overdesigned effects — see [[feedback-design-restraint]].

**Target users:**
- Primary: mid-to-high end restaurants and bars that want a premium digital presence
- Secondary: hotel bars, cocktail lounges, fine dining (Michelin-aspiring)

**Status as of 2026-05-27:** MVP single-cocktail demo working with vertical layered breakdown, bilingual EN/HE, menu landing page with 3D card. Real platform features (multi-tenant, CMS, AI pipeline, POS integration) all still ahead. See [[project-roadmap]].
