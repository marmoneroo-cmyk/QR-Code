# Feedback — Restaurant-first / Behavior Design (2026-05-30)

The product is now better than 95% of digital restaurant menus — reads as a "luxury interactive beverage experience," not a "QR menu." Next phase = **psychology + hospitality UX**, not more design polish.

## Core reframe
- Current feeling: **design-first / luxury concept art**. Needed: **restaurant-first**.
- Restaurateurs don't buy an art piece — they buy a **thing that increases ordering behavior**.
- Design goal for every screen: make a guest **stop → explore → understand fast → order more → share → return**.
- Luxury UX **removes**, doesn't add.

## Home page issues
1. **Too much empty black space** — feels "dead" on iPad/kiosk/low-brightness. Fix = add *atmosphere* (ambient fog gradients, soft reflections, light blooms, faint texture, depth layers, warm diffusion around cards), NOT brightness. Background should feel like a physical environment, not a void.
2. **Cards too small** — drinks must be hero objects (Apple-level product focus). Fewer cards/row, much larger drink imagery (+25–35%), less text. Typography must not compete with the drink.
3. **Category names too technical** ("Citrus & Refreshing"). Sell emotion, not classification → e.g. Golden Hour, Bright & Crisp, Deep & Smoky, Bitter Elegance, Sunset Spritz, Midnight Signatures.
4. **Too much UI chrome** (marquee, vertical text, badges, decorations). Remove ~30% of decorative UI — anything that doesn't help ordering.

## Detail (breakdown) page issues — bigger problems
- Feels like an **interactive infographic**, should feel like **luxury drink seduction**.
- **Biggest issue: the drink is too small.** Text + breakdown get more attention than the drink. Reverse it.
1. **Make the drink ~2× bigger** — the center of gravity of the whole screen.
2. **Far less text.** No paragraphs. e.g. "Hand-cut peel expressed over the glass…" → **"Fresh orange oils."** Short, sexy, fast.
3. **Dynamic breakdown** — don't show everything open (kills mystery). Enter = just the drink; scroll/tap/hold → ingredient explosion.
4. **Flavor profile**: radar chart feels 2018. Replace with **micro flavor tags** (Bitter · Citrusy · Effervescent · Herbal) — small, elegant, no radar.
5. **Bartender note**: too poetic / AI-luxury copy. Make it believable/real. "The Italian sunset in a glass…" → "Built for slow evenings and warm light."
6. **Color hierarchy**: palette (black + amber + cream) is good but flat. Add a **primary glow color per cocktail** (Aperol = warm orange, Margarita = lime green, Negroni = deep ruby) → emotional memory per drink.

## Missing — behavior/social features (THIS IS BIG)
- Share animated breakdown (TikTok bait), "Tonight's pick" / mood save, "What fits your mood?" recommender, AI pairing ("Best with oysters"), time-based menu (Golden Hour / Late Night), subtle mood soundtrack.
- Note: ambient audio, kiosk time-schedule, and pairings already exist in some form — refine/surface them rather than rebuild.

## Mindset
Stop building a beautiful interface; start designing **behavior**: stop, explore, order, share, return = hospitality psychology. Strong base already exists.
